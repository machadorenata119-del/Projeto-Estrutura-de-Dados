Sistema de Fila de Atendimento

Sobre o projeto

O Sistema de Fila de Atendimento é um projeto acadêmico desenvolvido para demonstrar a aplicação de Estruturas de Dados em uma situação real do cotidiano.

O sistema tem como objetivo organizar o atendimento de clientes por ordem de chegada, facilitando o controle da fila e o registro dos atendimentos realizados.

Objetivo

Desenvolver uma solução computacional utilizando três estruturas de dados:

- Fila (Queue): organiza os clientes pela ordem de chegada (FIFO).
- Lista (List): armazena o histórico dos atendimentos concluídos.
- Pilha (Stack): permite desfazer o último atendimento realizado (LIFO).

Funcionalidades

- Cadastro de clientes.
- Geração automática de senhas.
- Visualização da fila de espera.
- Chamada do próximo cliente.
- Histórico de atendimentos.
- Opção de desfazer o último atendimento.

Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript



Estruturas de Dados utilizadas

1. Fila (Queue)

Utilizada para organizar os clientes conforme a ordem de chegada. O primeiro cliente cadastrado será o primeiro a ser atendido.

2. Lista (List)

Utilizada para armazenar e apresentar os registros dos clientes que já foram atendidos.

3. Pilha (Stack)

Utilizada para controlar os atendimentos concluídos, permitindo desfazer o atendimento mais recente.

Comparação das estruturas

A fila é a estrutura mais adequada para organizar a ordem de atendimento, pois segue a regra FIFO.

A lista facilita a organização e consulta do histórico, enquanto a pilha permite controlar a última operação realizada.

Limitações

- Os dados não ficam salvos permanentemente.
- Ao fechar ou atualizar a página, as informações são reiniciadas.
- O sistema ainda não utiliza banco de dados.

Conclusão

O desenvolvimento deste projeto permitiu compreender a importância das Estruturas de Dados na resolução de problemas reais.

A utilização de fila, lista e pilha demonstra como diferentes estruturas podem trabalhar juntas para desenvolver uma solução computacional funcional e organizada.
